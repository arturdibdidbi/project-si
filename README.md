# N.H.A


O projeto consiste no desenvolvimento de um **aplicativo de produtividade e organização pessoal**, criado para ajudar o usuário a 
organizar seus objetivos, tarefas e atividades, acompanhar seu desenvolvimento e compreender melhor sua própria produtividade.


**Release 1**

| Release | Requisito | Feature |
|---|---|---|
| 1 | RF01 | Cadastro do usuário |
| 1 | RF02 | Login do usuário |
| 1 | RF03 | Cadastrar objetivos |
| 1 | RF04 | Resumo do dados por gráficos |
| 1 | RF05 | Bloquear aplicativos |

**Release 2**

| Release | Requisito | Feature |
|---|---|---|
| 2 | RF06 | Deletar conta |
| 2 | RF07 | Atribuir prioridades |
| 2 | RF08 | Gerenciamento de tarefas |
| 2 | RF09 | Registro de execução e acompanhamento do progresso |
| 2 | RF010 | Detecção de padrões de comportamento |
